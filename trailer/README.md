# yard trailer

A 32-second vertical (1080×1920, 9:16) trailer for yard, made with [Remotion](https://www.remotion.dev) and sized for TikTok, Reels and Stories. It has an original synthesized beat and sound effects. Cuts land on the music: 120 BPM, so a beat is 15 frames and a bar is 60.

## Beats
1. **Group chat (bars 1–4, quiet intro).** A friend texts "it's friday. wtm?", then shares a yard link card for Warehouse Party with Maya, Jordan and 3 friends going. "wait maya's going??" "say less."
2. **Drop: the app.** The rest plays like a screen recording, with a real iOS status bar, so nothing sits under the notch.
   - Feed: "every event in charlotte. one feed."
   - Tap into the event: "and who's actually going 👀", with the friends row ringed.
   - Tap Going, with a burst and a "you're Going 🎉" toast: "tap Going → you're in the group chat".
   - Event chat: "where the plan actually happens".
3. **Back in the texts (filtered bar).** "ok i'm Going", then "bet. see u at 9 🔥".
4. **End card.** "yard." slams in on the downbeat, then "know the move." and "charlotte · coming soon to the App Store".

## Run it (PowerShell, from `trailer\`)
```powershell
npm install
npm run studio    # live preview in the browser
npm run render    # writes out\yard-trailer.mp4
```
To change the music or sound effects, edit `scripts/make_audio.py` and run `python scripts/make_audio.py` (needs numpy). It rewrites `public/music.wav` and `public/sfx-*.wav`.

## Change it
- Texts, captions and timing: `src/Trailer.tsx`, with bar lengths in `src/theme.ts`.
- The text-thread look: `src/Messages.tsx`. It's a generic iOS-style thread drawn in code, not Apple's assets.
- App screens are demo-mode captures from `mobile/scripts/screenshot.cjs` (no real user data):
  - `public/feed-full.png` (`--full /`)
  - `public/event-open.png` (`/event/ev-005`)
  - `public/chat.png` (`/chat/ev-005?demoPlans=1`)

  Re-capture them after UI changes. If a layout moves, update the pt coordinates at the top of each scene: the tap spots and the friends row.
- Voiceover: drop a recording in `public/` and add `<Audio src={staticFile('vo.mp3')} />` in `Trailer`. Lower the music `volume` under it.
